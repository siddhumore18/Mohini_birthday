HOW TO ADD BACKGROUND MUSIC:
=============================

1. Drop your favorite MP3 audio file into this folder and name it:
   `birthday-bg.mp3`

2. That's it! When you click the 🎵 button at the bottom right, it will play your audio file smoothly in a loop.

3. Note: If no file is placed here, the website automatically generates a soft, soothing ambient music box melody using the browser's Web Audio API, so there is already sound and music ready out-of-the-box!
